# Squarespace LBO Case Study

An independent private-equity case study of Permira's acquisition of Squarespace, completed in October 2024. The project combines public transaction terms and historical company financials with transparent, illustrative financing and operating assumptions.

## What is included

- `Squarespace_LBO_Case_Study.xlsx` - five-year, formula-driven LBO model with a sources-and-uses bridge, operating forecast, debt paydown, returns summary, IRR sensitivity, source register, and model checks.
- `investment_memo.md` - concise investment view, returns analysis, and key risks.
- `sources.md` - public-source register and modelling conventions.

## Base-case result

The model assumes a five-year holding period, 5.0x entry debt / LTM adjusted EBITDA, 30.0% legacy shareholder rollover, 22.0x exit EBITDA multiple, and a full cash sweep to debt repayment. The base case produces:

| Metric | Result |
| --- | ---: |
| FY2028 revenue | $1,830.4m |
| FY2028 adjusted EBITDA | $530.8m |
| FY2028 adjusted EBITDA margin | 29.0% |
| Sponsor MOIC | 1.85x |
| Sponsor IRR | 13.1% |

The central conclusion is deliberately cautious: the entry valuation is demanding, so attractive returns require sustained growth, margin expansion, or a premium exit valuation. This makes the case useful in an interview because it shows valuation discipline rather than forcing a 20% IRR outcome.

## How to use the model

1. Open the `Assumptions` tab.
2. Select Base, Downside, or Upside with the case selector.
3. Adjust the yellow cells to test debt, rollover, operating, and exit assumptions.
4. Review the `Summary`, the native IRR sensitivity table, and the `Checks` tab.

Blue cells are hardcoded source data or explicit assumptions. Green formulas link to another worksheet. Black formulas calculate within the current worksheet.

## Important note

This is an educational, independent case study. It does not reproduce Permira's undisclosed financing structure, ownership arrangements, or investment underwriting. Public transaction terms and reported historical financials are sourced; all financing, operating, rollover, fee, and exit assumptions are clearly marked as illustrative.
